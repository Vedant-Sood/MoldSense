The integrated firmware/research pair was selected from existing release notes and its protocol contract. Earlier complete variants remain independent sketches.

`history/SOURCE_IMPORT.json` records the imported baseline's hashes before repository-specific fixes. It is not a checksum manifest of the modified final tree. SDK entries marked `local-only` are not published. September notes under `history/` describe earlier paths and verification; current instructions/results take precedence.

Excluded: virtual environments, installed toolchains, build caches, executables, personal databases, device backups/calibration blobs, unrelated presentations/chat notes, duplicate dependency trees and generated AI-Studio model exports. All historical sensor captures are excluded from the public repository. The legacy comparison handles absent references, and tests use generated synthetic signals. Experimental archives remain in the original project.

Restricted Bosch SDK components stay local and are installed with a hash-checked tool. Vendor sources retain attribution. The repository's original MIT license and initial GitHub commit are preserved.
